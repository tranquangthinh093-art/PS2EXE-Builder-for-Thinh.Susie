# PS2EXE-Builder-for-Thinh.Susie
This tool helps you convert .ps1 files into .exe executables, with support for .ico icons to represent the application.
To use it, place your .ps1 file and icon.ico file (the latter is optional) into the "PS2EXE Builder for Thinh.Susie" folder, then open that folder and run the "tool EXE Builder.bat" file to proceed.

The first step is to extract the downloaded zip file.
